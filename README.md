## 1. 何ができるか

### お客様側（トップページの構成）
1. **コンセプト** … 店の紹介が主役
2. **料金システム** … 実際の料金表（セット料金・チャージ・サービス料）
3. **初回限定プラン** … 一見様向け「ハウスボトルで60分 ¥15,000（税込）」
4. **遠隔オーダー（キャッチー案内）** … 「遠くからでも、乾杯を。」
5. **詳細** … 店内ギャラリー・ボトルメニュー（ダイジェスト）・スタッフ・Instagramライブ・アクセス

### 遠隔オーダーページ
- **遠隔オーダー**：写真付きメニュー（全56品）から選んでカートに入れ、指名スタッフ・メッセージ・開栓タイミングを指定して注文
- 注文後、店舗から届く **エアペイの決済リンク** でクレジットカード等で支払い

### 店舗（あなた）側
- **リアルタイム受注画面**（管理画面）：注文が入ると即座に表示＆通知音
- **メール通知**：kaori.bbp@gmail.com に注文内容が届く
- **LINE通知**：あなたのLINEに注文が届く（要設定）
- 入金ステータス管理（決済リンク未送付 → 送付済み → 入金確認済み）
- 開栓ステータス管理（新規 → 準備中 → 開栓済み → 完了）

## 3. 無料で公開する（クリックだけ・コマンド不要）

**このサイトは「Render」という無料のサーバーで公開できます。費用は一切かかりません。**
パソコンの難しい操作は不要で、ブラウザ上でポチポチ進めるだけです。

### 手順（所要15分）

**① GitHub にファイルを置く（ファイルの置き場所を作る）**
1. https://github.com を開き、「Sign up」で無料アカウント作成
2. 右上の「＋」→「New repository」をクリック
3. Repository name に `ginza-yashiro` と入力 →「Create repository」
4. 表示されたページで「uploading an existing file」というリンクをクリック
5. このフォルダの中身を全部ドラッグ＆ドロップ →「Commit changes」

**② Render で公開する（サイトを動かす）**
1. https://render.com を開き、「Get Started」で無料登録（GitHubアカウントでログインすると簡単）
2. ダッシュボードの「New +」→「Web Service」
3. 先ほどの `ginza-yashiro` リポジトリを選んで「Connect」
4. 設定は自動で読み込まれます（`render.yaml` を同梱しているため）。表示されたら一番下の「Deploy Web Service」をクリック
5. 数分待つと `https://ginza-yashiro.onrender.com` のようなURLが発行されます。これがお店のサイトです。

> 無料プランの注意点：15分間アクセスがないと一時的にスリープします（次にアクセスがあったとき約30秒で起動します）。常時起動させたい場合は月7ドルの有料プランがありますが、まずは無料で十分です。

### 独自ドメインを付けたい場合（任意・年1,000円〜）

「ginza-yashiro.com」のような自分だけのアドレスにしたい場合：
1. **お名前.com** などでドメインを取得（年1,000円〜）
2. Render の「Settings → Custom Domains」に取得したドメインを入力
3. お名前.comの設定画面で、Render が表示するレコードをコピペで設定
4. 数十分で `https://あなたのドメイン` でアクセスできるようになります（鍵マークのHTTPSは自動）

> まずは Render の無料URLで公開して様子を見て、気に入ったらドメインを付けるのがおすすめです。

## 4. 自分のパソコンで試す場合（任意・詳しい方向け）

1. Python 3 をインストール
2. このフォルダで以下を実行：
   ```bash
   pip install -r requirements.txt
   cp .env.example .env
   python server.py
   ```
3. ブラウザで開く：
   - サイト： http://localhost:8000/
   - 遠隔オーダー： http://localhost:8000/order
   - 管理画面： http://localhost:8000/admin?key=yashiro-admin-2026

## 5. メール通知の設定（Gmail）

注文が kaori.bbp@gmail.com に届くようにします。

1. Gmail で **2段階認証** を有効にする（Googleアカウント → セキュリティ）
2. Googleアカウントの「アプリパスワード」（https://myaccount.google.com/apppasswords）を開く
3. 「メール」を選択して16桁のパスワードを発行
4. `.env` に入力：
   ```
   SMTP_USER=kaori.bbp@gmail.com
   SMTP_PASS=発行した16桁のパスワード
   ```

## 6. LINE通知の設定

個人LINEへの自動送信はできないため、無料の **LINE公式アカウント** を作って通知します（あなたのLINEアプリに通知が届きます）。

1. **LINE公式アカウント** を無料作成（https://www.linebiz.com/jp/）
2. **LINE Developers**（https://developers.line.biz/）で Messaging API を有効化
3. チャネルアクセサストークンと、あなたのユーザーIDを取得
4. `.env` に入力：
   ```
   LINE_CHANNEL_ACCESS_TOKEN=（発行されたトークン）
   LINE_OWNER_USER_ID=（あなたのユーザーID）
   ```

> 未設定でもサイトは動きます（メール通知のみ）。

## 7. エアペイでのお支払いの流れ

店舗でお使いのエアペイの「**オンライン決済**」機能を使います。

### 前提：オンライン決済の有効化（初回のみ・無料）
1. エアペイ管理画面（https://merchant.airpayment.jp/）にログイン
2. メニューに「オンライン決済」があれば有効、なければ画面の案内から申込（無料）

### 注文が入ったときの操作（毎回・1分）
1. 管理画面（`/admin?key=...`）に新しい注文が届く（通知音＋メール）
2. 「💳 エアペイ管理画面」ボタンをクリック → エアペイにログイン
3. **都度決済**で注文の合計金額の決済リンクを作成
4. そのリンクをお客様のメールまたはLINEに送る
5. 管理画面で「リンク送付済み」を押す
6. 入金が確認できたら「入金確認済み」→ ご希望のタイミングで「開栓済み」

> 決済ブランド：Visa / Mastercard / JCB / Amex / QUICPay / d払い / au PAY など（お客様の画面のブランドがそのまま使えます）

## 8. Instagramライブの設定

開栓シーンは **Instagramライブ** で配信します。
サイトの「Instagramをフォロー」ボタンは **https://www.instagram.com/ginza.yashiro/** に設定済みです。

1. 開栓の時間になったら、お店のスマホからInstagramライブを開始
2. フォロワーのお客様に配信開始通知が届きます
3. 遠隔オーダーのお客様には、注文後のご案内（メール/LINE）で「Instagramで配信します」とお伝えする運用がおすすめです

> Instagramライブはサイトへの直接埋め込みができないため、サイトには「フォロー」ボタンと配信案内を表示しています。

## 10. メニュー・価格の変更

`data/menu.json` を編集します（メモ帳でも可）。例：

```json
{
  "id": "moet-brut",
  "name": "モエ・エ・シャンドン ブリュット",
  "category": "シャンパン",
  "price": 30000,
  "photo": "img/menu/moet.jpg",
  "description": "世界中で愛される定番シャンパン。"
}
```

- `price`：税込価格（数字のみ）
- `category`：カテゴリ名（フィルタに自動で出ます）
- `photo`：`static/img/` からのパス

**店内料金表**（セット料金・チャージなど）は `templates/index.html` の `SYSTEM` セクションに掲載済みです。変更があれば `system-table` の数字を書き換えてください。

**初回限定プラン**（¥15,000）は `templates/index.html` の `first-visit` セクションで編集できます。

## 11. 管理画面の使い方

**URL**：`https://あなたのドメイン/admin?key=（.envのADMIN_KEY）`

- このページを開いたままにすると、注文が入った瞬間に画面に表示され、通知音が鳴ります
- スマホのブラウザでも使えます（ホーム画面に追加しておくと便利）
- 「💳 エアペイ管理画面」ボタンで決済リンク発行画面にジャンプ
- ボタンで入金・開栓ステータスを更新

> ADMIN_KEY は `.env` で必ず変更してください（初期値のままだと誰でも入れてしまいます）。

## 困ったときは

- **サイトが開かない** → サーバーのログ（Render の Logs タブ）を確認
- **メールが届かない** → `.env` の SMTP_PASS がアプリパスワードか確認（通常のGmailパスワードでは不可）
- **写真が表示されない** → ファイル名が photos.css と一致しているか、`/* */` を外したか確認
